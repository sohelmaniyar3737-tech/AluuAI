# AluuAI

AluuAI is an independent AI assistant built with React, Vite, TypeScript, Tailwind CSS, an Express API, and PostgreSQL.

## Start here
Read [`MIGRATION-README.md`](./MIGRATION-README.md) for local setup, Neon schema setup, required environment variables, and Render deployment.

## Stack
- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express
- Database: PostgreSQL (Neon recommended)
- Authentication: bcrypt password hashes + signed JWT sessions
- AI: configurable OpenAI-compatible API endpoint
